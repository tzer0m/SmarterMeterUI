# SmarterMeter

[![Deploy](https://github.com/tzer0m/SmarterMeterUI/actions/workflows/deploy.yml/badge.svg)](https://github.com/tzer0m/SmarterMeterUI/actions/workflows/deploy.yml) [![Dependabot](https://github.com/tzer0m/SmarterMeterUI/actions/workflows/dependabot/dependabot-updates/badge.svg)](https://github.com/tzer0m/SmarterMeterUI/actions/workflows/dependabot/dependabot-updates)

A dashboard for home electricity meter readings — live usage chart, latest readings, and cost summaries based on configured tariffs. Built with ASP.NET Core Razor Pages, authenticated via Pocket ID (OIDC).

Live at [sm.tzer0m.co.uk](https://sm.tzer0m.co.uk).
